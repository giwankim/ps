# 달과 그림자

문제 ID: `MOON`

## 문제

#### 문제

재의는 매일 밤마다 달 사진을 찍는다. 사진에는 달과 달을 가리는 어두운 그림자가 보인다. 사진 상에서, 달과 그림자는 반지름이 각각 M과 S인 원이고, 달의 중심과 그림자의 중심 사이 거리는 C이다. 그림자에 가려지지 않은 달의 넓이를 구해보자.

## 입력

#### 입력

첫 번째 줄에 테스트 케이스의 수 T가 주어진다.  
각 테스트 케이스는 한 줄로 구성되며 M, S, C가 순서대로 주어진다. M, S, C는 모두 정수이다.  
(2 <= M < S < C <= 12, C < M + S)

## 출력

#### 출력

각 테스트 케이스에 대해, 그림자에 가려지지 않은 달의 넓이를 소수점 아래 넷째 자리에서 반올림하여 한 줄에 출력한다.

## 노트

#### 노트

파이(원주율)를 구하는 방법

```
// C++ 코드
#include <math.h>
double pi = acos(-1.0); // acos는 cos의 역함수를 의미한다.
```

```
// Java 코드
double pi = Math.acos(-1.0); // acos는 cos의 역함수를 의미한다.
```

소수점 아래 넷째 자리에서 반올림하여 출력하는 방법

```
// C++ 코드
double pi = acos(-1.0);
printf("%.3f\n", pi);
```

```
// Java 코드
double pi = Math.acos(-1.0);
System.out.printf("%.3f\n", pi);
```
